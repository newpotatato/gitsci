# Проект статьи (шаблон лаборатории)

| Папка | Что здесь |
|---|---|
| `paper/ru/`, `paper/en/` | Статья: русская версия (сначала) и английская (после апрува) |
| `paper/references.bib` | Библиография, у каждой записи DOI |
| `plan.yml` | План статьи: разделы, владельцы, сроки, статусы |
| `src/model.py` | Мат. модель (формулы из Methods) |
| `src/experiment.py` | Эксперименты |
| `src/plot.py` | Графики (стиль лаборатории) |
| `experiments/runs/` | Снимки запусков: версия кода + результат |
| `figures/` | Рисунки статьи (+ `.meta.json` для проверки стиля) |

## Как работать

1. Задачи и сроки создаются из `plan.yml`: `gitsci plan --sync` (в CI — автоматически на main).
2. Пишете RU-раздел в ветке → MR → руководитель ставит метку `ru-approved` → статус `approved_ru`.
3. Пишете EN-раздел → MR.
4. Каждый MR проверяется CI: формат, стиль, авторы, DOI, графики, план, эксперименты, код (ruff).
   Замечания видны прямо в MR (виджет Code Quality).

Локально: `pip install gitsci` и `gitsci all`.
