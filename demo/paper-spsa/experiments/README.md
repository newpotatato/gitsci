# Эксперименты

Каждый запуск — через снимок, иначе результат нельзя будет восстановить:

```bash
gitsci exp run -n baseline -o "figures/*.pdf" -- python src/experiment.py
gitsci exp list
gitsci exp diff <run_a> <run_b>   # чем отличался код (включая незакоммиченные правки)
```

В `runs/<run_id>/` сохраняются: команда, коммит, патч незакоммиченных изменений, окружение,
полный stdout/stderr, метрики и выходные файлы. Папку коммитим вместе с кодом.
