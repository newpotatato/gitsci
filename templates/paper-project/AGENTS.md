# Инструкции для LLM-агентов

Здесь только то, что отличается от обычной практики. Подробности — в skills
`.claude/skills/lab-writing-style` и `.claude/skills/lab-paper-check`.

- Текст статьи: без «;», без двух тире в одном предложении, формулы одной строкой,
  без «не X, а Y» и «воды». Проверка: `gitsci latex`.
- Статья пишется по разделам из `plan.yml`: сначала `paper/ru/`, EN — только после статуса `approved_ru`.
  Статус `approved_ru` не менять: его ставит руководитель.
- DOI не придумывать. После правок `references.bib` — `gitsci bib`.
- Эксперименты запускать только через `gitsci exp run ... -- <команда>`.
- Графики — только через `gitsci.mpl.use_style()` и `gitsci.mpl.save()`.
- Функция, реализующая формулу из статьи, содержит в docstring «Формула (N)».
