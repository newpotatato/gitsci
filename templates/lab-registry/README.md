# lab-registry — реестр участников лаборатории

Один файл на человека: `people/<id>.yml`. Поля — как в таблице на схеме:
ФИО рус, ФИ англ (без отчества), tg, ORCID, почта, аффилиации (с рабочей почтой), Scopus ID,
РИНЦ ID, WoS ID, LinkedIn, биография/CV рус/англ, библиография, дата актуализации.

**Актуализация — раз в 6 месяцев.** Обновили данные — поменяйте `updated`.
CI по расписанию заводит задачу владельцу записи, если она старше 6 месяцев.

CI проверяет формат ID (ORCID с контрольной суммой, Scopus, РИНЦ, WoS, почта, LinkedIn)
и собирает таблицу `registry.html` / `registry.md` (артефакт пайплайна).

Статьи сверяют авторов с этим реестром: написание ФИ, почту, аффилиацию.

```bash
gitsci registry . --table public/registry
```
